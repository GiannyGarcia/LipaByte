How this RAGbot works

Ask → Retrieve from knowledge base → Generate answer → Voice/text response

  1. You ask a LipaByte question.
  2. ElevenLabs retrieves relevant text from the uploaded knowledge files.
  3. The LLM answers using that retrieved context.
  4. You hear/see the response in the widget.
  5. If the answer is not in the knowledge base, the assistant should say it does not know.
